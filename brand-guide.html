03 — Logo

Logo System

The logo consists of two elements: the icon mark (t-shirt + bar chart + upward arrow) and the wordmark.

Primary horizontal lockup — use on headers, hero sections, large materials
On Dark Background
On Light Background
Icon Mark Only
✓ Do
  • Use official unmodified logo files
  • Maintain minimum 20px clear space on all sides
  • Minimum 200px width for full logo (web)
  • Minimum 32px for icon mark alone
  • Use on high-contrast, clean backgrounds
  • Use stacked lockup when width is constrained
✗ Don't
  • Never stretch, compress, or distort
  • Never change logo colors outside approved palette
  • Never add drop shadows, glows, or outlines
  • Never rotate or tilt the logo
  • Never place on cluttered or low-contrast backgrounds
  • Never use decorative effects of any kind

09 — Don'ts & Guardrails

What We Never Do

Run every asset through these checks before publishing or shipping.

✗ Visual Identity
  • Stretch, distort, or rotate the logo
  • Change logo colors outside palette
  • Add effects, shadows, or outlines to logo
  • Use colors outside the approved palette
  • Use neon, pastel, or off-brand colors
✗ Typography
  • Use Comic Sans, script, or decorative fonts
  • Use ALL CAPS for body text
  • Underline text that isn't a hyperlink
  • Use generic fonts as primary display type
✗ Messaging
  • Use hype language ("INSANE," "REVOLUTIONARY")
  • Make exaggerated or guaranteed claims
  • Use aggressive urgency ("Act now," "Limited time")
  • Position AI as a design tool — research only
  • Refer to users as "sellers" — always "creators"
✗ Brand Name
  • Splitting the official name into three spaced words
  • "Podtrackerpro" (wrong case)
  • All-lowercase multi-word misspellings
  • "PODtracker PRO" (wrong caps)
